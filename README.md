## 🚀 Tech Stack

- **Framework**: [SvelteKit 2](https://svelte.dev/docs/kit) with Svelte 5 Runes
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) with custom Executive Editorial design
- **Deployment Adapter**: [`@sveltejs/adapter-vercel`](https://kit.svelte.dev/docs/adapter-vercel)
- **Icons**: [`@lucide/svelte`](https://lucide.dev)
- **Scraper Prevention**: ROT13 client-side hydrated email protection
- **SEO & Discoverability**:
  - Full `schema.org` JSON-LD Structured Data (`Person`, `ProfessionalService`)
  - Dynamic XML Sitemap (`/sitemap.xml`)
  - Canonical crawler configuration (`/robots.txt`)
  - OpenGraph meta tags
